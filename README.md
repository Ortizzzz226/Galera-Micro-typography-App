# Galera

Microtipografía en español, retícula y composición de párrafos. Una app de Samuel Ortiz para Taller 1 (Universidad Jorge Tadeo Lozano).

**Abrir e instalar:** https://ortizzzz226.github.io/Galera-Micro-typography-App/

- **iPhone o iPad:** abre el enlace en Safari → Compartir → Agregar a pantalla de inicio.
- **Windows:** abre el enlace en Edge o Chrome → Instalar Galera.

Funciona sin internet después de abrirla una vez. Los proyectos se guardan en cada dispositivo. Para pasarlos de uno a otro, usa ☰ → Exportar y luego Importar.

Más detalles en [LEEME.md](LEEME.md).
